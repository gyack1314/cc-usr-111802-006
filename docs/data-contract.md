# 海平面海域数据约定

observation、reference、rule 三种记录分别表示观测、参照和区域规则。metric、region、unit 共同表示现有单期可比口径，来源版次与取得时间独立保留。

## 跨期趋势的观测元数据

跨期比较前，observation 记录可携带以下字段供四道可比性闸门核对；缺失任一字段的相邻时期不得并入同一可比区段：

- `period`：时期标识（如年份字符串）；缺省时取 `valid_from` 的年份。
- `product`：产品标识对象 `{"name", "version"}`，卫星产品的轨道处理版次变化体现为 version 变化。
- `network`：观测网络名称。
- `stations`：该时期纳入统计的站点标识列表。
- `station_links`：迁站延续链接，键为新站、值为其前身老站；仅登记在案的迁站可解释相邻时期的站点差异，其余新增/撤站判为覆盖断裂。
- `datum`：共同参照（基准框架）标识，相邻时期必须一致。
- `quality`：测量质量对象 `{"grade", "flags"}`，等级须落在可接受范围（默认 A、B）且不含阻断标记，否则该时期剔除并单列为无法判定，不参与趋势。

无法通过闸门的双时期形成区间断裂，质量不达标时期形成时期剔除；二者统一进入分析结果的 `undeterminable`，趋势只在剩余的可比区段内计算。
